# Hybrid AI v0.4
- Preserve verified native GGUF bridge and offline tools; online is initial selection, never automatic network access.
- Fixed HTTPS endpoints for Gemini, OpenRouter, Groq, OpenAI chat completions; user supplies model ID and API key. Connection test sends only a minimal test prompt.
- Session-only masked credentials; no disk persistence until Android Keystore integration. Persist no secrets. Explicit opt-in before sending robot notes, imported skill text or prior conversation to provider. No silent fallback.
- Limit requests, response body and time; disable redirects, use default TLS validation; cancellation is local and cannot guarantee provider billing stops.
- Reuse existing strict proposal validation and explicit approval, with permissions rechecked on execution. No remote tool execution.
- Add deterministic tests for request builder, parsing and error paths. Verify native and Android CI; live provider testing requires user's API key.
