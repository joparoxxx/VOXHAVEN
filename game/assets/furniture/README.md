# CUBYTE fitted office models

Original models: Kenney Furniture Kit, https://kenney.nl/assets/furniture-kit (CC0 1.0). GLB mirror: https://github.com/Hidencod/tge-assets/tree/main/packs/furniture-kit. Adapted for the 1.103-unit tall Cubot-update.glb: centered floor pivots, robot-scale XYZ dimensions, lit matte cream/slate/teal materials. See manifest.json for source model hashes, target bounds, triangle counts and provenance. All assets are self-contained GLB files. No runtime downloads. Charging pad remains custom procedural geometry, enlarged to 1.5 × 1.5 units. The 18 × 12 HQ footprint and navigation grid remain unchanged; workstation destinations move to 1.25 units from desk center, with expanded desk clearance. No arm IK or model replacement is included. Godot import and device verification are pending.
